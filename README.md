# dsh-market-watch

**DeepSeek Harness(dsh)的 Agent 增强型盯盘插件** —— 自选行情常驻侧栏、持仓盈亏账本、涨跌提醒、每日定时简报;同一份数据以 26 个 Agent 工具的形式暴露给模型。

> 定位一句话:**不做最重的 UI,做最懂 Agent 什么时候该说话的那一个。**
> 差异化来自 Agent 主动性:每日自动简报覆盖整个自选/持仓组合,快讯自动关联你的自选标的,而面板本身保持克制——模型替你先看一遍,而不是你让 Agent 看。

[English](./README.en.md) · 更新日志见 [CHANGELOG.md](./CHANGELOG.md)

**数据来自公开网页接口(新浪/腾讯/东方财富/金十),可能延迟、不准确或随时失效,不构成投资建议。**

## 功能总览

| 模块 | 能力 |
| --- | --- |
| 行情侧栏 | 自选分组(A 股/港股/美股/其他)、三态排序(原顺序含置顶/涨跌幅升序/降序)、行内展开 K 线详情 |
| 迷你条 | 常驻显示 1~3 个标的与持仓总收益率,不打开面板也能瞟一眼 |
| 多市场 | A 股、港股、美股、场内基金、期货(国内/国际)、外汇;A 股/港股/美股含盘口一档(bid1/ask1)与委比 |
| 持仓账本 | 份额/成本录入,自动计算当日盈亏、累计盈亏、收益率;港股/美股按汇率折算人民币(汇率缓存 5 分钟) |
| 涨跌提醒 | 价格/涨跌幅穿越阈值触发;**仅开市时段评估**、同一规则 3 分钟节流、宿主侧 5 秒定时器驱动(不依赖 UI 打开);未读角标;可选 Webhook 推送(默认关闭) |
| 定时简报 | `brief_schedule` 每日盘前 09:15 / 盘后 15:10(Asia/Shanghai)自动触发;休市日按 A 股交易日历自动跳过;盘后简报含持仓盈亏 |
| 快讯 | 金十快讯列表,支持关键词过滤与 60 秒缓存,由模型解读与自选的关联 |
| 资金流 | 沪深港通/北向资金、行业板块与概念板块资金流排行(单位:亿) |
| 分享卡片 | `share_card` 生成 SVG 收益榜,**金额字段无论何种设置都强制隐藏** |
| 数据迁移 | 自选/分组/持仓/提醒/设置 导出为带版本号的 JSON,跨环境导入 |

工程细节:页面不可见时 UI 轮询自动暂停、恢复即刷(FR-UI-07);网络请求只发生在宿主(Node)侧,浏览器侧只渲染;图表全部零依赖 SVG 自绘。

## 快速开始

```bash
# 1. 安装(Web 版 CLI;必须带 --profile)
dsh plugin --profile web add dsh-plugin-market-watch

# 2. 桌面版:在插件管理页输入 npm 包名 dsh-plugin-market-watch
```

安装后 5 分钟上手:

1. **加自选**:右侧栏点「添加」搜索(如输入「腾讯」→ `hk:00700`),或直接对 Agent 说「把贵州茅台加进自选」;
2. **录持仓**:侧栏行内「更多 → 设置持仓」,或说「我的 600519 成本 1450,1000 股」;
3. **让 Agent 替你看盘**:说「每天收盘后给我一份简报」即可创建定时任务。

## 与 Agent 对话

```text
「我的自选今天怎么样?」          → market_quote 批量行情,模型整理成表
「600519 涨过 1500 提醒我」       → alert_set,开市时段自动评估
「每天收盘后给我一份简报」        → brief_schedule(默认 15:10)
「现在有什么快讯,和我自选有关的?」 → market_news_flash + 模型关联解读
「查一下今天的北向资金」          → market_flow(kind=north)
「我的持仓这周表现如何?」        → holdings_get(隐私模式下只返回百分比)
```

标的代码规范为 `{market}:{code}`(如 `cn_sh:600519`、`hk:00700`、`us:AAPL.OQ`、`fund:110022`、`fut_cn:IF0`、`fx:susdcny`);对 Agent 说自然语言代码即可,搜索按裸代码/名称匹配(美股输入裸代码如 `AAPL` 可搜到,`us` 前缀前缀查询无效)。

## Agent 工具参考(26 个)

所有输出统一含 `asOf` / `source` / `delayed` 标注;延迟数据不冒充实时效;全部工具声明「不构成投资建议」。

### market_* — 行情数据

| 工具 | 参数 | 说明 |
| --- | --- | --- |
| `market_quote` | `symbols[]` | 批量行情:现价/涨跌额/涨跌幅/开高低/昨收/量额;A股/港股/美股另含 `bid1`/`ask1` 与委比 `orderBookRatio(%),源未提供时省略 |
| `market_fund_estimate` | `codes[]` | 基金盘中估值(约延迟 2 分钟,强制标注「估值」) |
| `market_search` | `q` | 名称/代码模糊搜索,返回市场/类型候选 |
| `market_kline` | `symbol`, `range?(1w/1m/3m/6m/1y)`, `format?(json/csv)` | 日 K 前复权;csv 格式节省 token |
| `market_fund_history` | `code`, `days?(默认 20)` | 基金历史净值(单位/累计净值与日涨幅) |
| `market_flow` | `kind(north/sector/concept)`, `limit?(默认 10)` | 北向资金 / 行业·概念板块资金流排行(亿) |
| `market_news_flash` | `limit?(默认 20)`, `keyword?` | 金十快讯,按时间倒序,60 秒缓存 |
| `market_fund_rank` | `sort?(day/year)`, `limit?(默认 10)` | 基金排行 |
| `market_export` / `market_import` | — | 自选/持仓/提醒/设置 带版本号导出导入 |
| `market_status` | `markets?` | 各市场开收盘状态与下次开盘时间(按交易日历跳过周末/节假日) |
| `market_diagnostics` | — | 数据源健康诊断:最近错误、最近成功时间、最近/平均延迟、冷却期状态 |
| `market_watch_hello` | — | 插件自检 |

### watchlist_ / holdings_ — 自选与持仓

| 工具 | 说明 |
| --- | --- |
| `watchlist_add` / `watchlist_list` / `watchlist_remove` | 自选增删查,重复添加幂等 |
| `holdings_set` | 录入持仓:股票成本价/数量/清仓;基金份额或金额(只有金额时按成本净值反推份额) |
| `holdings_get` | 持仓与盈亏查询(**默认隐私模式只返回百分比**,金额不出模型上下文) |
| `portfolio_summary` | 组合汇总:当日/累计盈亏、总收益率、涨跌分布、最大波动标的(受隐私模式限制) |

### alert_ / brief_ — 提醒与简报

| 工具 | 说明 |
| --- | --- |
| `alert_set` / `alert_list` / `alert_delete` / `alert_ack` | 提醒规则 CRUD;规则形如 `cn_sh:600519\|price\|up`,含最近触发信息;`alert_ack` 清除未读角标 |
| `brief_generate` | `kind=pre_open/post_close`;休市日返回 `closed=true`;盘后简报含持仓盈亏(已按隐私过滤、外币已折人民币) |
| `brief_schedule` | `kind`, `time?(默认 09:15/15:10)`;基于 `ctx.schedule` 的每日任务,投递绑定创建时的会话 |
| `share_card` | SVG 收益榜卡片(仅百分比与涨跌排行) |

## 配置参考

侧栏设置区直接修改,对话内修改同样生效:

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| 轮询间隔 `intervalMs` | 5000ms | 3~60 秒;页面不可见自动暂停,恢复即刷 |
| 涨跌颜色 `riseColor` | `red`(红涨绿跌) | 可反转为绿涨红跌 |
| 隐私模式 `privacy.exposeAmounts` | `false` | 关闭时持仓金额/份额/成本不进入模型上下文 |
| 排序 `sortMode` | `default` | 原顺序(置顶恒在组首)/ 涨跌幅升序 / 降序 |
| 提醒开关 `alertsEnabled` | `true` | 宿主侧定时器驱动,不依赖 UI 打开 |
| 迷你条标的 `miniBarSymbols` | 空 | 1~3 个常驻标的 |
| Webhook `webhookUrl` | 空 | 提醒触发时 POST 通知;非空才启用,地址视为敏感信息仅本地存储 |

## 数据源与可靠性

| 数据源 | 用途 | 状态 |
| --- | --- | --- |
| 新浪 `hq.sinajs.cn` | A 股行情(GB18030) | ✅ 实测有效,需 Referer |
| 腾讯 `qt.gtimg.cn` | 港股/美股行情、跨市场搜索 | ✅ 实测有效 |
| 东方财富 | 基金估值/历史净值/排行 | ✅ 实测有效 |
| 金十 | 市场快讯 | ✅ 实测有效 |
| 天天基金 `fundgz` | 基金估值(原方案) | ❌ 已下架,改用东财 |

可靠性模型(**单源可靠 + 缓存兜底**,ADR-0001):不堆砌多源适配器,可靠性来自——

- 主源失败(HTTP 429/403、超时、解析异常)时进入 60 秒冷却期,期间直接读缓存不再请求;
- 主源失败时返回过期缓存并标注 `stale`,UI 标注「已过期/估值/已收盘」,不被延迟数据误导;
- 休市市场不发高频轮询(FR-DATA-07):内置 2026 年 A 股节假日表 + 行情时间戳纠正,节假日/午休/收盘后自动降频。

## 隐私与安全

- **隐私边界**:默认只隐藏金额/份额/成本,不隐藏自选标的名单(ADR-0002):隐私模式下 Agent 查询持仓只返回百分比与方向,敏感金额不进入任何模型上下文(含云端);**例外是 `market_export`**:迁移场景显式导出全部数据(含持仓金额与 webhook 地址),不受隐私开关限制——请勿把导出 JSON 提交给不可信的一方;
- `share_card` 金额字段强制隐藏,不受隐私开关影响;
- Webhook 地址仅本地存储;插件不读取任何宿主凭据/API Key;
- 出站网络仅限上表行情数据源,仅宿主侧发起。

## FAQ

**Q:为什么提醒没有触发?**
提醒仅在**开市时段**评估(A 股 09:30–11:30 / 13:00–15:00 等,按标的所属市场),且同一规则 3 分钟内只触发一次;穿越判定需要两个拍点,规则创建后的第一个周期只建立基线。

**Q:面板刷新没了/布局重置了?**
浏览器侧布局仅存内存,dsh 会话页刷新后会折叠;从会话页头动作一键重新打开。

**Q:基金估值和官方净值为什么对不上?**
盘中显示的是估算值(约延迟 2 分钟),官方净值以收盘后披露为准;UI 与工具输出均强制标注「估值」。

**Q:代理/网络异常时怎么办?**
行情会回退到缓存并标注 `stale`;断网或代理故障时价格停止更新而非显示假实时,数据源的最近错误/延迟可从导出数据排查。

**Q:节假日为什么还在收到简报/轮询?**
不会——简报按 A 股交易日历自动返回「今日休市」,休市市场不发起高频轮询。节假日表为内置固定表(2026),**每年需随版本更新一次**。

## 已知限制

- 免费接口无 SLA,可能限频、改版或随时失效(缓解见「可靠性」);
- 交易日历为内置 2026 年 A 股节假日表,次年需手动更新;
- 期货/外汇标的在侧栏归入「其他」分组;
- **北向资金口径失效**:2024-08 起北向盘中净买入停止披露,`market_flow(kind=north)` 各字段实测恒为 0,待换用可得口径(见 issue);
- 迷你条的「持仓总收益率」依赖金额计算,默认隐私模式下不显示(百分比-only 数据不足以加权汇总);
- 免费搜索接口按裸代码/名称匹配:`usAAPL` 这类带市场前缀的查询无结果;
- 桌面版(Electron)安装链路需 npm 发布后实测;桌面 profile 由应用内置管理,CLI 不直接操作;
- 不做:交易下单、券商接入、量化回测、买卖建议、数字货币视图、移动端。
