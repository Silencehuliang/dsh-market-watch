# dsh-market-watch 产品设计

> 版本 v0.1 | 2026-11-09 | 上游依据:`需求说明文档(SRS).md`。本文档回答"做什么、给谁用、怎么用、状态如何呈现",不涉及具体视觉实现(见 `ui-design.md`)。

## 1. 产品定位与价值主张

一句话:**在 DeepSeek Harness 里低打扰地盯盘,并把行情变成 Agent 能直接用的数据。**

- 差异化(SRS G3):不是再做一个 AI 面板,而是把行情做成工具交给 dsh 自带的 Agent——用自然语言问自选、定时盘前盘后简报、由模型解读快讯。
- 核心价值(SRS G1):自选行情常驻可见、持仓盈亏、涨跌提醒、详情走势。
- 边界(SRS NFR-COMP):只做行情展示与信息整理,不做下单、不荐股、不承诺收益。

## 2. 用户画像与场景

| 画像 | 特征 | 核心诉求 | 关键场景 |
| --- | --- | --- | --- |
| 开发者型散户 | 用 dsh 写代码,顺便关心持仓 | 低打扰、开市时瞟一眼 | 迷你条挂 1~3 个标的,涨跌提醒 |
| Agent 深度用户 | 习惯自然语言交互 | 让模型替我整理,而非自己看盘 | 「看一下我的自选」「每天盘后给我复盘」 |
| 数据自控型 | 反感把持仓交给云端 | 隐私可控 | 隐私模式默认隐藏金额 |

## 3. 功能地图(信息架构)

```text
dsh-market-watch
├── 行情侧栏页(WatchTab)          —— 主界面
│   ├── 分组(默认:A股/港股/美股/基金 + 自定义)
│   ├── 自选列表(名称/代码/现价/涨跌幅/当日盈亏)
│   ├── 排序(原序含置顶 / 涨跌幅升序 / 降序)
│   ├── 添加(模糊搜索) / 删除 / 更多(持仓·分组·置顶)
│   └── 详情(点击进入:分时·日K·基金走势·历史净值·持仓·提醒)
├── 常驻迷你条(MiniBar)           —— 状态栏替代
├── 设置(Settings)
│   ├── 轮询间隔 / 涨跌颜色 / 迷你条标的 / 显示模板
│   ├── 隐私模式 / 启用的市场 / 数据源优先级 / 提醒开关
├── Agent 工具(17 个)              —— G2 双通道的「给人用」侧
├── 提醒(Alert)                    —— 价格/涨跌幅穿越 + 通知
├── 定时简报(Brief)                —— 盘前/盘后,由模型整理
└── 资讯(News)                     —— 快讯(M4)
```

## 4. 核心用户流程

### 4.1 首次安装 → 看到行情

```
安装插件 → 打开行情页(会话页头动作 / 侧栏入口)
→ 空状态:「还没有自选,点击添加」→ 搜索「腾讯」→ 候选 hk:00700
→ 添加 → 列表出现 → 现价/涨跌幅(基金标「估值」)
```

### 4.2 设置持仓 → 看到盈亏

```
列表行「更多」→ 设置持仓 → 输入成本/份额/数量 → 保存
→ 列表行出现当日盈亏;基金只有金额时按昨日净值反推份额
→ 迷你条汇总总盈亏
```

### 4.3 设置提醒 → 收到通知

```
详情页 → 提醒 → 添加规则(价格上穿 600) → 保存
→ 宿主侧轮询评估(无需 UI 打开)→ 穿越时弹通知
→ 通知内可「删除该规则」/「关闭全部提醒」
```

### 4.4 让 Agent 帮我

```
对话:「我的自选今天怎么样」→ 模型调 watchlist_list → 返回行情
「每天 15:10 复盘」→ brief 模板 + ctx.schedule → 定时简报
隐私模式默认下,模型只看到百分比,看不到金额
```

## 5. 状态与反馈设计

| 状态 | 触发 | 呈现 |
| --- | --- | --- |
| 空状态 | 无自选 | 「还没有自选,点击添加」+ 添加按钮 |
| 加载中 | 首次请求 | 骨架/占位,不阻塞 |
| 休市 | 非交易时段 | 标「已收盘」,展示最后价格 |
| 延迟数据 | 基金估值 | 标「估值(延迟约2分钟)」 |
| 数据失效 | Provider 全部失败 | 缓存数据 + 标「已过期」 |
| 错误 | 网络/代理异常 | 可读原因 + 「请检查代理」提示 |
| 隐私 | exposeAmounts=false | 仅作用于工具输出(进模型);UI 本地始终显示金额 |
| 无数据 | 接口不支持该标的 | 标「暂无数据」,可删除 |

## 6. 合规与免责的产品化呈现

- 三处必现:README、设置页、工具 description。
- 固定文案:「数据来自公开网页接口,可能延迟或不准确,仅供信息参考,不构成投资建议」。
- 界面与提示词禁止出现荐股、买卖点位、收益承诺文案(NFR-COMP)。
- 可选系统提示词段 `ctx.systemPrompt.section()` 约束模型「仅作信息整理」。

## 7. 里程碑对应的体验演进

| 里程碑 | 用户能做什么 |
| --- | --- |
| M0 | 验证插件可加载、tab 能开、迷你条位置选定、通知选型 |
| M1 | 在对话里「看一下我的自选」得到行情;加自选、设持仓、看盈亏(人民币标的) |
| M2 | 完整的行情侧栏页:分组、排序、涨跌颜色、迷你条、导入导出、主题/国际化 |
| M3 | 提醒、定时简报、详情页(K线/走势)、港股/美股/期货/外汇 |
| M4 | 资金流向、快讯、收益分享图、Webhook 推送、基金排行 |
