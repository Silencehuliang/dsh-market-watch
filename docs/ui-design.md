# dsh-market-watch UI 设计

> 版本 v0.1 | 2026-11-09 | 上游依据:`产品设计(product-design.md)`。本文档给出界面结构、组件规格与视觉规范,供 React 实现。设计原则:**融入 dsh 而非标新立异**——优先复用 dsh 主题 token 与组件,插件只在金融语义(涨跌、估值)上做克制强化。

## 1. 设计原则

1. **低打扰常驻**:行情始终可见但不抢注意力(SRS 4.2 观察 1)。
2. **跟随宿主**:颜色/圆角/字体全部走 dsh 主题变量,浅深色自动切换。
3. **语义清晰**:涨跌只用颜色 + 正负号,不靠文案堆砌;延迟/估值/过期必须显式标注。
4. **性能优先**:列表虚拟化,UI 更新节流 ≤ 1 次/秒,200 条不卡顿(FR-UI-07)。

## 3. 各界面设计

### 3.1 行情侧栏页(WatchTab,主界面)

- **分组栏**:横向 tab(A股/港股/美股/基金 + 自定义),「+」新建分组。
- **列表行**(核心组件,见 4.1):名称、代码、现价、涨跌幅;有持仓时追加当日盈亏。
- **操作**:行内「更多」→ 设置持仓 / 移动分组 / 置顶 / 删除;底部「添加」打开搜索。
- **排序**:点击表头三态循环(原序含置顶 → 涨跌幅升序 → 降序)。
- **已知限制**:布局仅存内存、刷新即折叠 → 必须有显眼入口 + 引导页入口(FR-UI-01)。

### 3.2 迷你条(MiniBar)

- 单行,展示 1~3 个选定标的 + 总盈亏;点击打开行情页。
- 候选挂载点:`conversation.input.*` / `conversation.composer.dock` / `shell.overlay`(M0 实测选定,无合适位置则降级为仅侧栏页,FR-UI-02)。

### 3.3 添加/搜索(FR-WL-02)

- 输入框模糊搜索(名称或代码)→ 候选列表(代码、名称、市场、类型)→ 点击添加,幂等去重。

### 3.4 详情页(Detail,FR-UI-04)

- 同一 tab 内二级视图:基本行情(现价/涨跌/开高低收)、分时与日 K、基金走势与历史净值、该标的的持仓与提醒。
- 图表零依赖 SVG 自绘。

### 3.5 设置页(Settings,FR-UI-05)

- 分组:轮询(间隔)、显示(涨跌颜色/迷你条标的/显示模板)、隐私(金额暴露开关)、市场(启用/数据源优先级)、提醒(开关/节流)。

## 4. 组件规格

### 4.1 QuoteRow(列表行)

| 属性 | 说明 |
| --- | --- |
| `name` + `code` | 左侧,名称主、代码次(次级色) |
| `price` | 右侧,等宽数字 |
| `percent` | 涨跌色 + `+`/`-` 前缀 |
| `badge` | 可选项:持仓·置顶·估值·已收盘 |
| 交互 | 点击进详情;悬停出「更多」菜单 |

### 4.2 其他组件

- `MiniBarItem` / `SearchBox` / `GroupTabs` / `HoldingEditor`(份额/金额/成本表单)/ `AlertEditor`(规则表单)/ `Sparkline`(SVG 迷你走势)/ `KLine`(SVG 日 K)/ `Badge`(状态标记)。

## 5. 视觉规范

### 5.1 颜色(涨跌)

> 优先取 dsh 主题的语义色;无对应时使用以下兜底值,随主题深浅微调。

| 语义 | 红涨绿跌(默认) | 绿涨红跌(反转) |
| --- | --- | --- |
| 涨 | `#E5484D` | `#12B76A` |
| 跌 | `#12B76A` | `#E5484D` |
| 平盘/无数据 | 中性次级色 | 同左 |

- 涨跌颜色为全局配置项 `riseColor`,默认红涨绿跌(中国习惯),可反转(FR-UI-05)。
- 其余颜色(背景/文字/边框/主色)一律跟随 dsh 主题变量,不硬编码。

### 5.2 排版

- 数字用等宽字体(`font-variant-numeric: tabular-nums`),价格与涨跌幅右对齐。
- 名称可截断(ellipsis),代码用小号次级色。
- 状态标注(估值/已收盘/已过期)用小号圆角徽章,降低视觉噪音。

### 5.3 间距与布局

- 列表行高紧凑(约 40px),分组 tab 高约 32px;迷你条单行 ≤ 24px 高。
- 200 条内用虚拟滚动保证流畅(FR-UI-07)。

### 5.4 图标

- 涨跌图标提供多套可选(SRS 4.1),默认用简洁三角/箭头;不用 emoji 作为语义主图标(可作趣味备选)。

## 6. 状态与反馈的视觉实现

| 状态 | 视觉 |
| --- | --- |
| 空状态 | 居中插画/图标 + 「还没有自选,点击添加」+ 主按钮 |
| 加载 | 行内骨架屏,不整页遮罩 |
| 休市 | 价格旁灰色徽章「已收盘」 |
| 估值 | 基金价格旁徽章「估值」,tooltip 注明「延迟约2分钟」 |
| 已过期 | 数据旁黄色徽章「已过期」 |
| 错误 | 可读错误文案 + 「请检查代理设置」引导 |
| 隐私 | UI 始终显示金额(本地不泄露);`***` 仅用于「收益分享图默认隐去金额」(FR-WL-08) |

## 7. 无障碍与国际化

- 涨跌不**仅**靠颜色区分:始终带 `+`/`-` 符号与百分比(色盲友好)。
- 文案走 `ctx.locale` 字典,中英双语(FR-UI-08)。
- 焦点可见、键盘可操作(搜索框、菜单、表单)。
