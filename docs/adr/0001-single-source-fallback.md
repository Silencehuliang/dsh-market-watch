# 数据层采用「单源可靠 + 缓存兜底」而非多源回退

多数资产只有一个免费数据源(基金估值=天天基金、A 股实时=新浪、港股=腾讯),「多源回退」对它们无从谈起。因此 FR-DATA-03 / G4 从「多源回退(P0)」改为「单源可靠 + 缓存兜底 + 源健康监控」,仅对确有第二个免费源的场景(如 A 股行情)配置 Provider 优先级回退。

**Considered Options**:① 严格多源(所有资产至少两个源,需引入需 token/付费的第二源,增加成本与合规负担,与「免费接口」初衷相悖);② 单源+兜底(选定)。选择②是为了避免为空写不存在的适配器,把可靠性重心放到缓存兜底与源健康监控上。

**Consequences**:「限频 + 冷却期(默认 60 秒)+ 缓存兜底」成为数据层核心;FR-DATA-03 的验收相应改为「主源失败返回缓存并标注已过期」。
