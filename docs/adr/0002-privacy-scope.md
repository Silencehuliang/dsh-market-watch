# 隐私模式只隐藏金额,不隐藏自选标的名单

工具结果会进入模型上下文(云端),FR-TOOL-01 默认隐藏金额/份额/成本价,但自选标的名单(用户关注什么)默认可读。原因:watchlist_list / holdings_get 等工具的价值就在于读自选,连标的都隐藏会废掉 G2 双通道的核心能力;标的名本身敏感度低于金额。

**Consequences**:若后续有强隐私需求,可再加独立的标的可见性开关,而不是在隐私模式里一并隐藏。

## 修订(2026-11-11,#32)

`market_export` 曾无视隐私开关整体 dump 持仓金额与 webhook 地址进模型上下文,与本决策冲突。修订:**导出默认脱敏**(持仓只含 closed/updatedAt 结构字段,settings 去除 webhookUrl),显式传 `full=true` 才完整导出——把「金额是否进入模型上下文」的决定权交还给用户的明确指令,而非模型的默认行为。币种(USD/HKD)与汇率缺失标注 `fxMissing` 判定为非敏感量,两种模式均下发(#33)。
